# 糯糯的小房间

根据三张参考照片创作的 3D 风格虚拟角色与网页养成小游戏。角色居中，可以点击和滑动摸摸、喂食、洗香香、睡觉、送花，以及玩 15 秒接星星小游戏。

本地版本已完成。GitHub Pages 公开发布正在等待用户明确同意公开生成角色素材。

预定发布地址：`https://7-an.github.io/momo-room/`（尚未上线）。

## 玩法

- 摸摸增加开心度与亲密度；点心增加饱食度；睡觉每分钟恢复 4 点元气。
- 接星星增加开心度、亲密度和星星糖；每局消耗 10 点元气。元气不足 30 时需要先休息。
- 完成每天 5 次摸摸、1 次喂食、1 次陪玩，可额外获得 20 颗星星糖；10 颗糖可以送一束花。
- 右上角可以开启音效和改名；房间内可以切换日光与晚风配色。
- 进度仅保存在当前浏览器的 localStorage，没有服务器、录音、账号或跨设备同步。清理浏览器数据会清除进度。
- 所有主要操作支持键盘和触屏；角色素材是 3D 渲染图像与动作动画，不是实时三维模型。

## 本地预览

无需安装依赖。在项目目录运行：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

访问 `http://127.0.0.1:4173`。ES 模块需要 HTTP 服务，请不要直接双击 HTML 使用 `file://`。

## GitHub Pages

纯静态站点。将本仓库上传 GitHub，在 Settings → Pages 选择 Deploy from a branch，并选择 `codex/momo-room` 分支的 `/ (root)`。没有构建步骤或网络依赖。

## 文件

- `index.html`：页面结构、按钮与弹窗。
- `style.css`：房间、布局、响应式与动画。
- `app.js`：触摸、音效、存档和接星星小游戏。
- `model.js`：养成状态、离线恢复、亲密度与每日奖励规则。
- `assets/character.png`：生成后的四状态角色图。
- `ASSET_PROMPT.md`：角色生成方式与完整提示词。
- `tests/model.test.mjs`：状态与奖励检查，使用 Node.js 22.7 或更新版本运行 `node tests/model.test.mjs`。
