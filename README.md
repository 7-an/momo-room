# 啵啵的房间

根据三张参考照片创作的 3D 风格虚拟角色与网页养成小游戏。角色名为啵啵。刚认识时是礼貌、有距离的陌生人，只能打招呼；熟悉之后才逐步接受照顾，傲娇和关心也会随关系增加。

用户已明确确认参考照片获得公开授权，并授权公开生成角色素材与上线小游戏。

[打开啵啵的房间](https://7-an.github.io/momo-room/)

此游戏纯为虚构。

## 关系与玩法

| 关系 | 累计亲密度 | 可用互动 |
| --- | ---: | --- |
| Lv. 1 陌生人 | 0 | 只能打招呼 |
| Lv. 2 点头之交 | 18 | 聊天、一起接星星 |
| Lv. 3 逐渐熟悉 | 42 | 加入带点心、送花、陪伴休息 |
| Lv. 4 亲近的朋友 | 66 | 加入摸摸 |
| Lv. 5 特别的默契 | 90 | 加入洗香香，全部互动开放 |

- 每个关系阶段只需 3 次有效招呼或聊天即可进入下一阶段；陪玩和其他已开放互动也能增加亲密度。陌生人每次打招呼获得 6 点亲密度；熟悉后聊天获得 8 点。每次间隔至少 3 秒，让上一句话说完。
- 初期点击角色只是打招呼，不会出现摸摸动作和爱心；Lv. 4 之后才可以点击或滑动抚摸。未解锁动作在页面和状态逻辑中均受限制，不会改变状态或发奖励。
- 白天、夜间房间、音效和名字设置不改变关系。原有存档的亲密度、星星糖、状态和自定义名字继续保留，旧默认名自动改成啵啵。
- 点心增加饱食度；睡觉每分钟恢复 4 点元气；接星星每局 15 秒，增加开心度、亲密度与星星糖，每局消耗 10 点元气，元气不足 30 时需要先休息或聊天。
- 每日心愿根据当天开始时的关系阶段安排，只使用当时已开放的互动。完成可额外获得 20 颗星星糖，同一天只领取一次；10 颗糖可送一束花，送礼需要 Lv. 3。
- 进度仅保存在当前浏览器的 localStorage，没有服务器、录音、账号或跨设备同步。清理浏览器数据会清除进度。
- 主要操作支持键盘和触屏。角色素材是 3D 渲染图像与动作动画，不是实时三维模型。

## 角色加载

网页使用保留透明背景和原分辨率的 WebP 角色图，体积由 2,249,786 字节降为 414,146 字节（约减少 82%）。HTML 提前以高优先级预加载，四种动作共用一张图，切换互动不用再下载。PNG 原图仅作素材保留，网页不请求它。

## 本地预览

无需安装依赖。在项目目录运行：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

访问 `http://127.0.0.1:4173`。ES 模块需要 HTTP 服务，请不要直接双击 HTML 使用 `file://`。

## GitHub Pages

纯静态站点。将本仓库上传 GitHub，在 Settings → Pages 选择 Deploy from a branch，并选择 `codex/momo-room` 分支的 `/ (root)`。没有构建步骤或网络依赖。

## 文件

- `index.html`：页面结构、按钮与弹窗。
- `style.css`：房间、布局、响应式与动画。
- `app.js`：触摸、音效、存档和接星星小游戏。
- `model.js`：养成状态、关系阶段、权限检查、离线恢复与每日奖励规则。
- `dialogue.js`：从陌生到亲近的五阶段对白和页面语气。
- `assets/character.webp`：网页优先加载的压缩四状态角色图。
- `assets/character.png`：保留的生成原图。
- `ASSET_PROMPT.md`：角色生成方式与完整提示词。
- `tests/model.test.mjs`：状态与奖励检查，使用 Node.js 22.7 或更新版本运行 `node tests/model.test.mjs`。
